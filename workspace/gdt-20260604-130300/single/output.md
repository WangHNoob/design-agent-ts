# 竞技狂欢·公会争霸版 — 系统设计文档

## 1. 概述

### 1.1 需求背景
在原有「竞技狂欢」活动模板（包含竞技任务 + 竞技大赛）的基础上，新增**以公会为单位参加**的竞技模块，丰富公会成员之间的协作与竞争体验，提升公会活跃度和PvP热度。

### 1.2 设计目标
- 在现有竞技狂欢框架下，新增**公会竞技榜**模块
- 公会成员的个人PvP表现可转化为公会积分，参与公会排名
- 保持与原有竞技任务、竞技大赛的兼容性，三者并列展示
- 活动结束时按公会排名发放全公会奖励

### 1.3 关联系统
| 系统 | 关系说明 |
|------|----------|
| 公会系统（union） | 公会基础数据、成员管理 |
| 公会战（UnionWar） | 公会排名与赛季机制参考 |
| 排行榜系统 | 公会竞技榜排名展示 |
| 原有竞技狂欢 | 竞技任务 + 竞技大赛，本设计为扩展 |
| ActivityEntrance | 活动入口配置 |

## 3. 核心玩法设计

### 3.1 公会竞技榜规则

**基本规则：**
1. 活动期间，公会成员通过参与竞技任务和竞技大赛获得**个人贡献分**
2. 个人贡献分自动累加至所属公会的**公会总积分**
3. 全服公会按总积分进行排名
4. 活动结束时，根据排名发放公会奖励（公会全体成员均可领取）

**个人贡献分获取途径：**

| 途径 | 贡献分规则 | 说明 |
|------|-----------|------|
| 完成每日任务 | 每完成1个每日任务 +X分 | X由数值策划配置 |
| 完成每周任务 | 每完成1个每周任务 +Y分 | Y由数值策划配置 |
| 完成挑战任务 | 每完成1个挑战任务 +Z分 | Z由数值策划配置 |
| 竞技大赛连胜 | 每获得1场连胜 +W分 | W由数值策划配置，连胜场数越高单场分可递增 |
| 竞技大赛达到指定连胜档位 | 达到3/5/7/10连胜时额外加分 | 各档位加分由数值策划配置 |

**公会总积分公式：**
```
公会总积分 = Σ(公会所有成员的个人贡献分)
```

**排名规则：**
- 按公会总积分从高到低排序
- 积分相同时，先达到该积分的公会排名靠前
- 仅活动期间有≥1名成员产生贡献分的公会参与排名

### 3.2 奖励框架

**个人贡献奖励（达到指定贡献分节点可领取）：**

| 档位 | 条件 | 奖励类型 |
|------|------|---------|
| 个人贡献分达到A | 累计X分 | 个人奖励（待数值策划配置） |
| 个人贡献分达到B | 累计Y分 | 个人奖励 |
| 个人贡献分达到C | 累计Z分 | 个人奖励 |

**公会排名奖励（活动结束后通过邮件发放）：**

| 排名区间 | 奖励类型 | 说明 |
|----------|---------|------|
| 第1名 | 公会全员奖励 | 称号/头像框/道具等 |
| 第2~3名 | 公会全员奖励 | 称号/头像框/道具等 |
| 第4~10名 | 公会全员奖励 | 道具奖励 |
| 第11~50名 | 公会全员奖励 | 道具奖励 |
| 参与奖 | 公会全员奖励 | 基础参与奖励 |

> 注：具体数值由数值策划配置，此处仅定义结构和档位框架。

### 3.3 与原有模块的关系

- **竞技任务**和**竞技大赛**的原有玩法、奖励完全保留
- 公会竞技榜**不新增独立战斗玩法**，而是复用竞技任务和竞技大赛的行为数据
- 玩家完成竞技任务/竞技大赛时，同步获得个人贡献分
- 三个Tab页互相独立但数据互通

## 5. 数据流与交互逻辑

### 5.1 核心数据流

```
玩家完成竞技任务/竞技大赛
        │
        ▼
任务完成回调 → 检查活动是否开启公会竞技榜
        │
        ├── 否 → 结束
        │
        └── 是 → 计算个人贡献分
                    │
                    ▼
                更新玩家个人贡献分（本地/服务端）
                    │
                    ▼
                累加至公会总积分
                    │
                    ▼
                更新公会排行榜
```

### 5.2 关键交互逻辑

| 场景 | 逻辑 |
|------|------|
| 玩家加入/退出公会 | 加入公会时，个人已有贡献分带入新公会；退出时，个人贡献分从原公会扣除（仅活动期间） |
| 活动进行中公会解散 | 该公会从排行榜移除，成员个人贡献分清零 |
| 积分相同排名 | 先达到该积分的公会排名靠前 |
| 奖励发放时机 | 个人节点奖励：达到条件后手动领取；公会排名奖励：活动结束后系统通过邮件自动发放 |

---

## 6. 奖励发放流程

### 6.1 个人贡献奖励
- 玩家在公会竞技榜界面查看个人贡献分进度条
- 达到节点时，节点变为可领取状态（红点提示）
- 点击领取，通过掉落组产出奖励
- 活动结束后未领取的个人奖励通过邮件补发

### 6.2 公会排名奖励
- 活动结束后，系统根据最终排名结算
- 按排名区间通过邮件向公会全体成员发放奖励
- 奖励邮件包含：道具奖励 + 称号/头像框（如有配置）
- 活动结束后7天内加入公会的成员不追溯领取

---

## 7. 异常处理

| 异常场景 | 处理方案 |
|----------|---------|
| 活动期间玩家退出公会 | 个人贡献分保留，但不再计入原公会；加入新公会后方可继续累积 |
| 活动期间更换公会 | 个人贡献分转移至新公会 |
| 服务器时间校准 | 以服务器时间为准，活动开始/结束时间与ActivityEntrance配置一致 |
| 排行榜数据异常 | 每日凌晨4点定时全量重算一次排行榜 |
