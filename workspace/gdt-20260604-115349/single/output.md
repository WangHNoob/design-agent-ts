# 公会版竞技狂欢 系统设计文档

## 1. 需求背景与目标

### 1.1 立项背景
现有「竞技狂欢」活动（参见 `activities/pvp活动模板.md`）已上线运营一段时间，定位为 PvP 拉热度的限时活动模板，但其玩法局限在 **个人维度**（每日/每周/挑战任务 + 连胜奖励），缺少社交沉淀。本期需要在保留既有"个人赛道"的基础上，**新增以公会为单位参加的赛道**，借助公会（`union` 表族）的组织力放大 PvP 热度，同时拉动公会活跃与公会战意识。

### 1.2 设计目标
1. **提升 PvP 总参与度** — 通过公会荣誉/排名拉非核心 PvP 玩家入场
2. **拉动公会活跃** — 让会长/管理员有运营动机（招呼成员上线打 PvP）
3. **复用既有资产** — 优先复用 `ActivityWeekPVPTask`、`UnionWar`、`union` 等已有表族，避免重复造轮子
4. **可配置可复用** — 整体作为「活动模板」，每期换皮即可上架

### 1.3 非目标（本期不做）
- 不引入新的实时对战玩法，公会赛道复用现有 PvP 战斗结算
- 不涉及数值具体平衡（由数值策划另行配置）
- 不涉及跨服匹配（沿用现有公会战服务器分组规则）

## 2. 系统总览

### 2.1 模块划分

```
竞技狂欢（活动总入口）
├── 个人赛道（既有，保留）
│   ├── 竞技任务（每日/每周/挑战任务）
│   └── 竞技大赛（连胜奖励）
└── 公会赛道（本期新增）⭐
    ├── 公会贡献榜（成员个人 PvP 积分汇总到公会）
    ├── 公会排行榜（同服公会按总积分排名）
    ├── 公会阶段宝箱（公会总积分达到档位，全员领取）
    └── 公会赛季奖励（活动结束按公会排名 + 个人贡献档位发放）
```

### 2.2 模块定位说明

| 模块 | 参与单位 | 触发源 | 结算频率 | 复用 |
|------|----------|--------|----------|------|
| 公会贡献榜 | 个人 → 公会 | 完成任意 PvP 战斗即累计 | 实时 | 复用 `ActivityWeekPVPTask` 任务结构 |
| 公会排行榜 | 公会 | 公会总积分 | 实时刷新，每日整点更新展示 | 复用 `UnionWarRank` 排行思路 |
| 阶段宝箱 | 公会 | 公会总积分达到档位 | 实时解锁 | 复用 `新绝境` 阶段奖励交互 |
| 赛季奖励 | 公会 + 个人 | 活动结束邮件下发 | 一次性 | 复用 `UnionWar/UnionWarReward` |

## 3. 玩法详设

### 3.1 公会贡献规则

**积分获取来源**（与个人赛道同一套 PvP 战斗）：
- 完成一场普通 PvP 战斗 → 个人积分 +A，公会积分 +A
- 胜场 → 额外 +B
- 连胜（复用既有连胜计数）每达到一档 → 额外 +C
- 完成每日/每周/挑战任务 → 一次性 +D

**积分汇入规则**：
- 玩家完成 PvP 战斗时，若已加入公会，积分双计：个人榜 + 公会榜
- 玩家退会后获得的积分 **不计入原公会**，并入新公会（无公会则不计入公会榜）
- 入会冷却（沿用游戏既有 7 天退会冷却）期间产生的积分照常归属当前公会

**参与门槛**：
- 个人：达到 PvP 解锁等级
- 公会：公会等级 ≥ X（建议复用 `_UnionSeaFightActivity.unlockUnionLev` 同款字段）

### 3.2 公会排行榜

- 范围：同服 + 跨服匹配组（沿用 `UnionWarServerGroup` / `_UnionSeaFightServerGroup` 的分组策略，本期默认按 **同服**，配表可切换）
- 排名规则：公会总积分降序，同分时按"先达成时间"升序
- 展示：Top 50 公会，玩家可见自己公会当前排名、上下 1 名公会、与第 1 名差距
- 刷新：积分实时累计；排名展示每 5 分钟刷新（与既有排行榜节奏一致）

### 3.3 公会阶段宝箱

参照 `新绝境` 阶段奖励交互：
- 公会总积分达到档位（如 10w / 30w / 60w / 100w / 150w）后，**全公会成员**都可在活动界面领取该档奖励
- 玩家领取窗口：达成时刻起至活动关闭后 24 小时
- 单玩家需满足"个人贡献 ≥ 该档位最低个人门槛"才能领取（防搭车）
- 可领取置顶，已领取置底（沿用新绝境规则）

### 3.4 公会赛季奖励

参照 `UnionWar/UnionWarReward` 的多档结构：
- 按公会最终排名分档（如 1 / 2-3 / 4-10 / 11-30 / 31-50 / 未上榜）
- 每档内再按 **个人贡献** 二次分档（如个人 Top10% / Top30% / 其它）
- 活动结束后 30 分钟内通过邮件统一下发
- 奖励包含但不限于：荣誉称号、限定头像框、公会专属道具、通用资源（具体数值由数值策划配置）

### 3.5 与个人赛道的关系

- 入口共用：主界面活动图标点入后，顶部 Tab 切换"个人赛道 / 公会赛道"
- 数据互通：同一场 PvP 战斗同时为两边产出积分，**不冲突、不二选一**
- 解锁顺序：未加入公会的玩家可见公会赛道 Tab，但内容置灰，引导加入公会

## 4. 界面流程

### 4.1 主界面入口

```
世界主界面
   └─ 活动图标（ActivityEntrance）
         └─ 竞技狂欢主面板
                ├─ Tab1：竞技任务（个人，既有）
                ├─ Tab2：竞技大赛（个人，既有）
                └─ Tab3：公会争霸（公会，新增）⭐
```

### 4.2 公会争霸 Tab 布局

```
┌───────────────────────────────────────┐
│  公会争霸  [活动剩余时间 03d 12h]      │
├───────────────────────────────────────┤
│  我的公会：xxx  当前排名：第 7 名      │
│  公会总积分：125,430                  │
│  我的贡献：3,250（公会内第 12 名）      │
├───────────────────────────────────────┤
│  [阶段宝箱进度条]                      │
│  ▣ 10w ▣ 30w ▣ 60w ☐ 100w ☐ 150w     │
│  [领取] x2 可领                       │
├───────────────────────────────────────┤
│  [公会排行榜]  [公会内贡献榜]  [奖励预览] │
└───────────────────────────────────────┘
```

### 4.3 关键交互流

1. **领取阶段宝箱**：点击宝箱 → 校验"公会积分达档 && 个人贡献达门槛" → 弹窗确认 → 发奖 → 红点消除
2. **查看公会排行榜**：点击 → 弹窗显示 Top50 + 自身公会卡片置顶吸附
3. **查看公会内贡献榜**：点击 → 弹窗显示本公会成员贡献排名，长按头像可查看其简要信息
4. **未加入公会**：点击公会争霸 Tab → 提示"加入公会后可参与"→ 跳转公会主界面

## 5. 数据流与模块依赖

```
[PvP 战斗结算]
       │ 推送结算事件
       ▼
[竞技狂欢服务] ──→ 写入 个人积分（既有）
       │
       └──→ 校验 玩家公会归属
              │
              ├──→ 写入 公会总积分（新）
              ├──→ 写入 公会内贡献（新）
              └──→ 触发 阶段宝箱解锁广播（新）
                     │
                     ▼
              [公会成员客户端] 收到红点 + 全公会公告

[活动关闭 Timer]
       │
       ▼
[赛季结算服务] ──→ 拉取公会排名快照
                 ──→ 拉取每会成员贡献快照
                 ──→ 按表配置生成邮件奖励
                 ──→ 批量下发
```

| `ActivityEntrance` | 主界面入口注册 |
| 邮件系统 | 赛季奖励下发 |
| 排行榜服务 | 公会排名与公会内贡献排名 |
| 红点系统 | 阶段宝箱可领、新排名变化提示 |

| 依赖本系统 | 说明 |
|------------|------|
| 暂无 | 本系统是叶子节点 |

## 6. 配表设计（DESIGN 模式 · Markdown 方案）

> 复用约定：能复用既有表族字段含义就复用，新表统一前缀 `PvPCarnivalUnion`（竞技狂欢-公会版）。

### 6.1 活动总开关 — 复用既有

**`ActivityEntrance/ActivityEntrance`**：新增一行 `typeId` 用于公会版竞技狂欢主入口（沿用既有字段，无结构变更）。

### 6.2 新增表 1：`PvPCarnivalUnion/PCUActivity` — 活动期次配置

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | int | 主键 | 期次 ID |
| `seasonName` | string | 非空 | 期次名称（如"第 1 期：盛夏争霸"） |
| `openTime` | datetime | 非空 | 活动开启时间 |
| `closeTime` | datetime | 非空，> openTime | 活动关闭时间 |
| `settleTime` | datetime | 非空，≥ closeTime | 赛季结算时间（发奖） |
| `unlockUnionLev` | int | ≥1 | 公会参与最低公会等级（参考 `_UnionSeaFightActivity.unlockUnionLev`） |
| `unlockPlayerLev` | int | ≥1 | 个人参与最低等级 |
| `serverGroupId` | int | 外键 → `PCUServerGroup.id` | 服务器分组（决定公会排行榜范围） |
| `rankSnapshotInterval` | int | 秒，默认 300 | 排行榜展示刷新间隔 |
