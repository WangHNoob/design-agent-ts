# 竞技狂欢（公会扩展版）系统设计文档

## 一、概述

### 1.1 设计目标
在原「竞技狂欢」PvP 活动模板（个人维度）的基础上，新增**公会维度**的竞技玩法，鼓励公会成员协作参与 PvP，提升 PvP 热度与公会归属感、活跃度。

### 1.2 设计范围
- 保留并复用原有「竞技任务」与「竞技大赛（连胜奖励）」个人玩法。
- 新增「公会竞技」子模块：以公会为单位累计 PvP 战绩，按公会贡献发放个人奖励，并按公会总积分发放公会榜单奖励。

### 1.3 参考来源
- 知识库：`activities/pvp活动模板.md`（竞技狂欢原模板）
- 知识库：`activities/新绝境优化.md`（公会合作活动参考）
- 配表：`ActivityEntrance/ActivityEntrance`、`union/*`、`UnionBoss/*`、`UnionBounty/*`

## 二、整体架构

### 2.1 模块划分

```
竞技狂欢（活动入口）
├── 子界面 1：竞技任务      [个人]  —— 复用原模板
│   ├── 每日任务
│   ├── 每周任务
│   └── 挑战任务
├── 子界面 2：竞技大赛      [个人]  —— 复用原模板
│   └── 连胜奖励（连胜达 N 场领奖，失败 M 次重置）
└── 子界面 3：公会竞技      [公会] ★新增
    ├── Tab A：公会积分赛   —— 个人贡献累计为公会积分
    ├── Tab B：公会任务     —— 公会成员协作完成
    ├── Tab C：公会排行榜   —— 全服公会积分排名
    └── Tab D：奖励中心     —— 个人贡献奖励 + 公会榜单奖励
```

### 2.2 模块依赖

| 新模块 | 依赖系统 | 说明 |
|---|---|---|
| 公会竞技 | 公会系统（union） | 需玩家已加入公会，未加入公会的玩家入口置灰并提示 |
| 公会竞技 | 现有 PvP 玩法（如荣耀连战、竞技场） | 复用 PvP 战斗数据作为贡献来源 |
| 公会竞技 | 排行榜系统 | 公会榜单展示与发奖 |
| 公会竞技 | 邮件系统 | 活动结束后发奖通过邮件下发 |
| 活动入口 | ActivityEntrance/ActivityEntrance | 活动开关、图标、红点 |

### 2.3 数据流

```
玩家参与 PvP 战斗（胜利）
        ↓
个人贡献值 +X（按 PvP 类型权重）
        ↓
    ┌───┴────┐
    ↓        ↓
个人累积   公会积分池（公会内所有成员贡献累加）
    ↓        ↓
个人贡献奖励   公会榜单结算
（实时领取）   （活动结束后排名发奖）
```

## 三、详细设计

### 3.1 入口与开放规则
- **入口位置**：主界面活动图标 → 竞技狂欢
- **开放配置**：通过 `ActivityEntrance/ActivityEntrance` 配置开关与开放/关闭时间
- **活动周期**：建议 1 周/期（具体由运营决定）
- **公会竞技子模块前置条件**：玩家已加入公会，且公会等级 ≥ X（由 `union/UnionLev` 控制）
- **结算时机**：活动关闭后次日 1:00 统一结算公会榜单并发奖（与 `新绝境` 发奖时间一致）

### 3.2 子界面 3：公会竞技 — 详细流程

#### Tab A · 公会积分赛
- **核心机制**：玩家在指定 PvP 玩法（竞技场、荣耀连战等）中每胜利一场，按玩法类型获得「公会贡献值」，同时累加到公会积分池。
- **失败保护**：失败不扣分；可配置「连败补偿」机制（连败 N 场后下次胜利获得双倍贡献）。
- **每日贡献上限**：每个玩家每日贡献上限可配（防爆肝）。
- **UI 元素**：
  - 顶部：公会名 / 公会积分 / 当前全服排名
  - 中部：个人贡献值 / 今日剩余可获取上限 / 历史累计
  - 底部：参与的 PvP 玩法快捷入口（点击跳转）

#### Tab B · 公会任务
- **核心机制**：每周刷新一组公会任务（如「公会成员累计胜场 100 次」「公会击败外服公会成员 50 次」），完成后公会积分池获得额外奖励，且所有公会成员获得参与奖。
- **完成机制**：任意成员行为推进任务进度，达成后公会内任意成员可点击「领取到公会仓库 / 触发个人邮件」。

#### Tab C · 公会排行榜
- **榜单维度**：全服公会按公会积分降序排名
- **展示信息**：排名、公会名、公会等级、公会积分、会长名、当前公会的实时排名
- **刷新频率**：服务器每 5 分钟刷新一次榜单缓存
- **跳转**：点击公会名可查看公会详情（复用现有公会信息界面）

#### Tab D · 奖励中心
| 奖励类型 | 触发条件 | 发放方式 |
|---|---|---|
| 个人贡献阶梯奖励 | 个人贡献值达到阈值 | 界面内手动领取 |
| 公会任务完成奖励 | 公会任务达成 | 界面内手动领取 |
| 公会榜单奖励 | 活动结束按公会名次发放 | 邮件下发到全公会成员 |
| 公会冠军专属奖励 | 公会榜第 1 名 | 邮件下发 + 全服公告 + 限定称号/外观 |

### 3.3 反作弊与边界规则
- **退会限制**：活动期间最后 24 小时内退会的玩家，不享受公会榜单奖励（与新绝境退会限制对齐）。
- **新入会限制**：活动期间最后 24 小时内入会的玩家，不享受公会榜单奖励。
- **解散公会**：活动期间公会解散，公会积分作废，个人已领取的贡献奖励保留。
