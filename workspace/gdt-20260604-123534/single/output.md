# 系统设计文档：竞技狂欢·公会争锋赛季（新版）

## 一、需求概述与设计目标

### 1.1 需求来源
策划提案：在现有「竞技狂欢」（个人 PvP 活动模板）基础上扩展一期新的活动版本，新增**以公会为单位参加**的玩法模块，提升公会内部凝聚力、撬动公会成员组织参与 PvP。

### 1.2 设计目标
- **保留个人维度**：沿用现有「竞技任务 + 竞技大赛（连胜）」框架，无破坏式改动
- **新增公会维度**：本期新加一条「公会争锋」子页签，公会成员的 PvP 行为可累积公会积分、参与公会排名、获取公会专属奖励
- **节奏匹配**：活动周期与现有公会节奏（周一刷新 / 周四赛事日）对齐，避免冲突
- **独立可配**：所有新增内容通过配表驱动，便于复用为后续赛季

### 1.3 设计范围
| 范围 | 内容 |
|------|------|
| ✅ 含 | 活动结构、子页签划分、积分/排名规则、奖励框架、配表结构 |
| ❌ 不含 | 具体数值（连胜阈值、积分系数、奖励掉落表）→ 数值策划负责 |
| ❌ 不含 | UI 视觉稿、动效 → UI/美术设计负责 |
| ❌ 不含 | 底层 PvP 战斗逻辑（沿用已有玩法）|

## 二、模块划分与整体架构

### 2.1 顶层结构

```
竞技狂欢（限时活动入口，ActivityEntrance 一级图标）
├─ 子页签 1：竞技任务      （沿用·个人维度）
├─ 子页签 2：竞技大赛      （沿用·个人维度·连胜奖励）
└─ 子页签 3：公会争锋 ★新增（公会维度）
   ├─ 模块 3.1 公会贡献榜  — 公会内成员积分排名
   ├─ 模块 3.2 公会争锋榜  — 全服公会积分排名
   ├─ 模块 3.3 公会任务    — 公会集体目标
   └─ 模块 3.4 奖励中心    — 个人贡献奖励 + 公会排名奖励
```

### 2.2 模块依赖关系

```
[竞技狂欢活动入口]
        │
        ├── 复用 ──> [ActivityEntrance/ActivityEntrance]  （活动开放时间）
        │
        ├── 复用 ──> [已有 PvP 玩法]（来源：竞技场、荣耀连战等胜负事件）
        │              │
        │              ▼
        │       [战斗结算事件总线]  ─── 派发 ───┐
        │                                       │
        ├── [个人维度] ←─ 任务/连胜监听 ←──────┤
        │                                       │
        └── [公会维度·公会争锋] ★              │
              │   │                             │
              │   ├── 监听战斗结算 ←────────────┘
              │   ├── 依赖 [union/union 公会基础数据]（公会 ID、成员列表、等级）
              │   ├── 依赖 [union/UnionLev]（公会等级影响奖励上限）
              │   └── 写入 [新增配表 ArenaCarnival/*]
              │
              ▼
        [活动结算·邮件发奖]
```

### 2.3 与现有系统的关系

| 系统 | 关系 | 说明 |
|------|------|------|
| `ActivityEntrance` | 复用 | 配置入口图标、开放/关闭时间、红点 |
| `union/union` 表族 | 依赖 | 读取公会基础信息、成员关系 |
| `union/UnionLev` | 依赖 | 公会等级 → 解锁本活动子页签的最低等级 |
| 既有 PvP 玩法（如竞技场） | 复用 | 战斗胜负即为积分输入源 |
| `荣耀连战` | 兼容 | 同一场 PvP 战斗可同时触发本活动积分与荣耀连战状态，不互斥 |
| `新绝境`（公会 Boss） | 错峰 | 新绝境为 PvE 周常；本活动为 PvP 限时，建议时间错开 |

## 三、界面流程与交互逻辑

### 3.1 主入口流程

```
[主界面] → 点击「竞技狂欢」活动图标
   │
   ▼
[竞技狂欢主界面]
   ├─ 顶部：剩余时间倒计时 + 活动规则按钮
   ├─ 中部：3 个子页签（竞技任务 / 竞技大赛 / 公会争锋★）
   └─ 默认选中：竞技任务（保留原行为）
```

### 3.2 公会争锋子页签流程 ★ 新增

```
[公会争锋页签]
   │
   ├─ 未加入公会
   │     → 灰显，弹窗提示「需加入公会后参与」+ 跳转公会界面按钮
   │
   ├─ 公会等级不足（< 配置门槛 unlockUnionLev）
   │     → 显示锁定状态 + 提示当前/所需等级
   │
   └─ 正常进入
         ├─ 顶部信息条
         │    ├─ 我所在公会名称 / 头像
         │    ├─ 公会当前总积分
         │    ├─ 公会全服排名
         │    └─ 我的个人贡献积分
         │
         ├─ 中部主视图（Tab 切换）
         │    ├─ Tab A：公会贡献榜（默认）
         │    │      → 展示本公会成员积分排序 Top N
         │    ├─ Tab B：公会争锋榜
         │    │      → 展示全服公会积分排序 Top N
         │    └─ Tab C：公会任务
         │           → 列出本期公会集体任务（如：累计胜场、累计参与人数）
         │
         └─ 底部
              ├─ 「我的奖励」按钮 → 弹窗展示个人贡献档位奖励
              └─ 「公会奖励预览」按钮 → 弹窗展示公会排名档位奖励
```

### 3.3 积分获取交互

- **无显式入口**：积分通过既有 PvP 战斗结算自动累积，不另设进入按钮
- **结算飘字**：战斗结算面板新增一行「竞技狂欢·公会积分 +X」（活动期间显示）
- **每日积分上限**：单玩家每日贡献给公会的积分有上限（防刷号），达上限后战斗仍正常进行但不再累计

### 3.4 红点规则

| 触发条件 | 红点位置 |
|----------|----------|
| 公会任务有未领取奖励 | 活动入口 → 公会争锋页签 → 公会任务 Tab |
| 个人贡献奖励可领取 | 活动入口 → 公会争锋页签 → 「我的奖励」按钮 |
| 活动结算后公会奖励待领取 | 活动入口 → 公会争锋页签 |

## 四、核心规则

### 4.1 积分规则
- **积分来源**：活动期间，玩家在指定 PvP 玩法中的战斗结算（胜/负/平均可配置不同积分）
- **公会积分** = ∑（本公会全体成员的个人积分，受单人每日上限约束）
- **结算时机**：实时累计；排行榜按固定间隔刷新（参考 `UnionSeaFightTime.refreshRankTime` 模式）

### 4.2 排名规则
- **公会内贡献榜**：公会成员按个人积分降序；同分按达成时间先后
- **全服公会争锋榜**：公会按总积分降序；同分按总积分达成时间先后；支持服务器分组（参考 `UnionWar/UnionWarServerGroup`）

### 4.3 奖励发放
| 奖励类型 | 触发 | 发放方式 |
|----------|------|----------|
| 公会任务奖励 | 公会集体完成任务 | 公会成员各自在面板点击领取 |
| 个人贡献档位奖励 | 个人积分达到档位阈值 | 面板手动领取 |
| 公会排名奖励 | 活动结束结算 | 邮件发放，按公会最终排名档位 |
| 公会领袖额外奖励 | 公会进入指定排名 | 邮件单独发给会长/副会长（参考 `USFRankAwards.managerTitleId`）|

### 4.4 防作弊与限制
- 单玩家每日贡献积分上限（配表项 `dailyContribMax`）
- 退会玩家在活动期间的积分**保留**给原公会（结算锁定），新入公会的玩家不可向新公会贡献已结算积分
- 加入公会需满足最小天数（参考新绝境「退会限制同步」规则），防止临时跳会
